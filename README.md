# DreamShader documentation website

Next.js + Fumadocs static documentation.

See [DOCS_SYNC.md](DOCS_SYNC.md) for plugin-owned bilingual documents, AI configuration kept on this website, and Chinese translation PRs reviewed and merged in the plugin repository before publication; [DEPLOYMENT.md](DEPLOYMENT.md) covers deployment.

Local checks: `npm run docs:test`, `npm run docs:validate`, `npm run typecheck`, `npm run build`, then `python -B scripts/check-links.py`.
