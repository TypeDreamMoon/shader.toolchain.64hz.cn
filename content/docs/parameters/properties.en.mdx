---
title: Property Types
description: Every type token a Properties declaration accepts — 39 compact tokens, 22 parameter node tokens (15 of which build), their defaults, how Graph reads them and their call forms.
---

A declaration in a `Properties` section becomes a named node in the generated material — a material
parameter an instance can override, a constant, or a builtin input node. Which node is decided by the
type token you write: the token selects the Unreal expression class, decides how the default is
written, and for a few types decides whether the declaration can be **called** from `Graph` to wire
input pins.

There are two ways to name a type. **Compact tokens** (`float`, `vec3`, `Texture2D`) say what the value
is and let DreamShader pick the node; **explicit `*Parameter` tokens** (`TextureSampleParameter2D`,
`ChannelMaskParameter`) name the Unreal expression class directly. Prefer the compact tokens, and reach
for an explicit token only when the compact set cannot do the job.

<Since v="2.0.0" /> A 1.x source is read by the legacy front end, which turns each property into what
the 2.0 language writes for it: a `uniform`, a `static const`, or a parameter node built where it is
read. The `.dss` spelling is in [DreamShaderLang 2.0](/en/docs/language-v2);
[`dsc migrate`](/en/docs/language-v2/migrate) writes it for you.

## Declaration shape

<Synopsis>
```c
[const] <type-token> <name> [ = <default-value> ] [ [ <metadata-entry> { ; | , } … ] ] ;
```
</Synopsis>

<Grammar />

The `[ … ]` around `<default-value>` and around the whole metadata block is the "optional"
meta-bracket; the metadata block's own brackets are **literal punctuation**. A declaration with metadata
is written `float A = 1.0 [Group="X"];`. Metadata syntax is in [Metadata and groups](/en/docs/parameters/metadata),
the enclosing section grammar in [Sections](/en/docs/language/sections#properties).

Every type token is **case-insensitive**. `FLOAT3`, `Float3` and `float3` are the same token.

## Four kinds of token

| Kind | Count | Example | Node generated |
| :-- | :-- | :-- | :-- |
| Compact scalar | 7 | `float Strength = 1.0;` | `UMaterialExpressionScalarParameter` |
| Compact vector | 27 | `vec3 Tint = vec3(1, 1, 1);` | `UMaterialExpressionVectorParameter` |
| Compact texture | 5 | `Texture2D Base = Path(Game, "T_X");` | `UMaterialExpressionTextureObjectParameter` |
| Explicit `*Parameter` node | 22, of which 15 build | `TextureSampleParameter2D Tex;` | the named `UMaterialExpression` subclass |

A fifth form, `UE.<Name>( … ) <name>;`, declares an engine input node (UVs, time, vertex colour, a
collection read) as a property — see [UE.\* nodes](/en/docs/builtins/ue-nodes#properties-declaration-form).

A token that matches none of these is `DSH3252`; one of the seven parameter node tokens that have no 2.0
spelling is `DSH3253` <Since v="2.0.0" />.

### Which form to use

| Goal | Write | Why |
| :-- | :-- | :-- |
| A float the artist can tweak on an instance | `float`, `half`, `int`, `uint`, `bool` (or `ScalarParameter`) | All seven compact scalar tokens and `ScalarParameter` produce the identical `ScalarParameter` node |
| A colour or 2/3/4-component parameter | `float2` … `bvec4` | The declared component count controls which output `Graph` reads (`RG` / `RGB` / `RGBA`) |
| A four-component parameter that always reads as RGBA | `VectorParameter` | Fixed at 4 components |
| A texture the shader samples itself | `Texture2D` / `TextureCube` / `Texture2DArray` / `Texture3D` / `VolumeTexture` | A texture *object* parameter of that dimension |
| A texture with its own sampler node and configurable sampling | `TextureSampleParameter2D` and friends | Owns `Coordinates` and mip pins; takes `SamplerType` / `MipValueMode` metadata |
| A texture object with no fixed dimension | `TextureObjectParameter` | Takes its dimension from the default asset <Since v="1.6.0" /> |
| A compile-time branch | `StaticSwitchParameter` | Must be used in the call form `N(True = …, False = …)` |
| A compile-time boolean with no branch | `StaticBoolParameter` | Value only |
| A baked value the artist must not change | `const <compact-token>` | A constant node — no parameter, no instance override |
| A node the engine feeds (UVs, time, camera, vertex colour, MPC) | `UE.<Name>( … )` | See [UE.\* nodes](/en/docs/builtins/ue-nodes) |
| Any other `UMaterialExpression` class | `UE.<Class>( … )` | Generic reflected construction — see [Generic UE.Expression](/en/docs/builtins/ue-expression) |

## Compact scalar tokens

Seven spellings, identical in every observable respect: `float`, `float1`, `half`, `half1`, `int`,
`uint`, `bool`. Each makes a `UMaterialExpressionScalarParameter`, or with `const` a
`UMaterialExpressionConstant`. `int1`, `uint1` and `bool1` are scalar tokens too <Since v="2.0.0" />: the
token is read as the 2.0 type of that name, and HLSL spells a scalar that way.

<Callout type="info">
`int`, `uint`, `bool` and `half` carry **no** integer, boolean or precision semantics at the node level.
Every one makes a float `ScalarParameter`, and the material graph performs no truncation. Write them for
readability, not behaviour.
</Callout>

### Scalar defaults

```c
float A = 0.5;    float B = -2;    float C = 2.5f;    float D = 1e3;    float E = true;
```

The value is a number — an optional sign, digits with at most one `.`, an optional exponent (`1e3`,
`2.5E-1`), an optional trailing `f` — or `true` / `false` (any case), which are `1.0` and `0.0`. Anything
else is `DSH3254` (2.0.0 – 2.1.0 refused an exponent too, which 1.x read; it is accepted again
<Since v="2.1.1" />). A number glued to letters, such as `1abc`, is not even one token: it is `DSH2105`
<Since v="2.0.0" /> (1.x read it as `1.0`).

With no `= <default>` the default is `0`.

## Compact vector tokens

27 spellings: `float2`–`float4`, `half2`–`half4`, `vec2`–`vec4`, `int2`–`int4`, `uint2`–`uint4`,
`bool2`–`bool4`, `ivec2`–`ivec4`, `uvec2`–`uvec4`, `bvec2`–`bvec4`. Every one makes a
`UMaterialExpressionVectorParameter` whose `DefaultValue` is a full `FLinearColor`; only the **declared
component count** — the digit the token ends in — differs, and it decides which node output a `Graph`
read targets. With `const` the node is a `Constant2Vector`, `Constant3Vector` or `Constant4Vector` by
component count; a 3-component `Constant3Vector` is forced to `A = 1.0`.

`vec*`, `ivec*`, `uvec*` and `bvec*` are GLSL-flavoured spellings only, behaving exactly like `float*`,
`int*`, `uint*` and `bool*`. There is no compact token for a 1-component *vector*: `float1` and `half1`
are scalars.

### Vector defaults

<Synopsis>
```c
<anything> ( <part> [ , <part> ] … )
```
</Synopsis>

| Rule | Behaviour |
| :-- | :-- |
| Text before `(` | **ignored** — `float4(…)`, `vec3(…)`, `(…)` and `banana(…)` all parse |
| Delimiters | from the first `(` to the **last** `)` |
| Parts | split on every `,`; empty parts are dropped; each part is a number (sign, digits, one `.`, an exponent, a trailing `f`), or `true` / `false` |
| 1 part `a` | `(a, a, a, 1)` |
| 2 parts `a, b` | `(a, b, 0, 0)` |
| 3 parts `a, b, c` | `(a, b, c, 1)` |
| 4 parts `a, b, c, d` | `(a, b, c, d)` |
| More than 4 parts | parts 5 and beyond are **never read** — not even parsed |
| No `( … )`, or a part unparsable | `DSH3254` |

The declaration keeps the first *N* of those four values, *N* being its component count, and the
parameter node's `DefaultValue` is those *N* with the missing channels `0` and alpha `1`:
`float2 T = float2(4, 4)` is `(4, 4, 0, 1)` <Since v="2.0.0" /> (1.x wrote `(4, 4, 0, 0)`).

With no `= <default>` the default is `(0, 0, 0, 1)` for a 2- or 3-component token and `(0, 0, 0, 0)` for
a 4-component one <Since v="2.0.0" /> (1.x left the node's own default).

<Callout type="warn">
**The declared component count is never checked against the literal's arity.**
`float2 P = float4(1, 2, 3, 4);` and `float4 P = vec2(1, 2);` both parse. The literal fills four values
by the table above and the declared count keeps the leading ones — so `float4 P = vec2(1, 2)` yields
`(1, 2, 0, 0)` read as RGBA. The token before `(` is not validated either, so a typo such as
`flaot3(1, 0, 0)` is accepted silently. Keep the literal's arity and spelling in step with the declared
token.
</Callout>

## Compact texture tokens

Five spellings, four distinct dimensions. Every one makes a texture **object** parameter (with `const`,
a `UMaterialExpressionTextureObject`) — the node carries the asset but does not sample it.

| Token | Texture type |
| :-- | :-- |
| `Texture2D` | `Texture2D` |
| `TextureCube` | `TextureCube` |
| `Texture2DArray` | `Texture2DArray` |
| `Texture3D` | `VolumeTexture` <Since v="1.3.8" /> |
| `VolumeTexture` | `VolumeTexture` <Since v="1.3.8" /> |

`Texture3D` and `VolumeTexture` are exact synonyms. To sample one, hand it to a sampling call in `Graph`,
or declare a `TextureSampleParameter2D` instead.

### Texture defaults

```c
Texture2D A = Path(Game, "Textures/T_X");
Texture2D B = Path("/Game/Textures/T_X");
Texture2D C = "/Game/Textures/T_X";                              // bare quoted absolute path
Texture2D D = /Script/Engine.Texture2D'/Game/Textures/T_X.T_X';  // pasted from Copy Reference
```

The bare quoted form exists since <Since v="1.5.0" />; the `Class'…'` reference the Content Browser's
**Copy Reference** puts on the clipboard can be pasted as it stands <Since v="1.9.0" />. Every form is in
[Asset references](/en/docs/parameters/path). The default is resolved when the material is built: a
reference that does not resolve is `DSH8271` (whose message quotes the resolver's own code), one that
resolves to nothing loadable `DSH8218`. A `const` texture's default is written to its `TextureObject`
node's `Texture` property instead, where an asset that does not load is written as nothing, with no
diagnostic — see [Metadata and groups](/en/docs/parameters/metadata#object-properties).

### Defaults when no asset is assigned

| Declared texture type | Fallback asset |
| :-- | :-- |
| `Texture2D` | the node's own default, `/Engine/EngineResources/DefaultTexture` |
| `TextureCube` | `/Engine/EngineResources/DefaultTextureCube.DefaultTextureCube` |
| `VolumeTexture` | `/Engine/EngineResources/DefaultVolumeTexture.DefaultVolumeTexture` |
| `Texture2DArray` | **none exists** |

<Callout type="warn">
`Texture2DArray` has no engine fallback. A `Texture2DArray` declared without `= Path(…)` keeps the
node's 2D default texture, which is not an array, and the compiler says nothing <Since v="2.0.0" />
(1.x refused the declaration). Assign an explicit array asset.
</Callout>

### Dimension validation

<Since v="2.0.0" /> The asset a default loads is **not** checked against the declared dimension. What
is checked, before anything loads, is the class a Content Browser reference names in its `Class'…'`
shell: a texture class of another dimension is `DSH1044`, and a class DreamShader knows is not a
texture (`MaterialFunction`, `CurveLinearColor`, `Font`, …) is `DSH1043`. See
[Asset references](/en/docs/parameters/path#class-checking).

After the asset is assigned, `AutoSetSampleType()` runs unless the declaration says `SamplerType`, so
the sampler type follows the asset — see [SamplerType](/en/docs/parameters/metadata#samplertype).

## `const` declarations

<Since v="1.2.6" /> A `const` declaration makes a constant node instead of a parameter: its name is not
in the material's parameter list and an instance cannot override it.

```c
const float Gamma = 2.2;                       // Constant
const vec3  Sky   = vec3(0.2, 0.4, 0.9);       // Constant3Vector
const Texture2D Lut = Path(Game, "T_Lut");     // TextureObject
```

`const` goes with the 39 compact tokens and, <Since v="2.0.0" />, with `ScalarParameter`,
`VectorParameter` and `TextureObjectParameter`, which then build the same constant as `const float`,
`const float4` and `const Texture2D`. On any other `*Parameter` token it is `DSH3253`; on a `UE.*`
declaration it is ignored <Since v="2.0.0" />.

A `const` property keeps only what a constant node has <Since v="2.0.0" />: `Description` and
`SamplerType` reach a `const` texture's `TextureObject` node; on a `const` scalar or vector the
description is dropped, and `Group`, `SortPriority` and `Slider` — written, or inherited from a
`Group(…)` scope — are `DSH7224` warnings. A `Graph` read of a `const` vector is the whole value of its
constant node, not a named `RG` / `RGB` / `RGBA` output.

## Parameter node tokens

22 tokens that name an Unreal parameter expression class directly; the set is closed.
<Since v="2.0.0" /> Each token takes one of three 2.0 forms:

- **a declaration** — `ScalarParameter`, `StaticBoolParameter`, `VectorParameter` and
  `TextureObjectParameter` are the `uniform` a compact token would make (`float`, a `/// @static`
  `bool`, `float4`, `Texture2D`), with one parameter node however often it is read;
- **expanded at each use** — the other eleven that build are no declaration: every read or call is a
  reflected `UE.Expression(Class = "<Token>", ParameterName = …, …)` call carrying the default and the
  metadata, and uses written the same way share one node;
- **no 2.0 spelling** — seven tokens are `DSH3253`. Move such a material to a `.dss` and build the node
  with [`UE.Expression`](/en/docs/builtins/ue-expression).

<Wide>

| # | Token | 2.0 form | Generated class | `= default` accepts | `Graph` use |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 1 | `ScalarParameter` | declaration | `UMaterialExpressionScalarParameter` | scalar literal | value |
| 2 | `StaticBoolParameter` | declaration | `UMaterialExpressionStaticBoolParameter` | `true` / `false` only | value |
| 3 | `StaticSwitchParameter` | expanded | `UMaterialExpressionStaticSwitchParameter` | `true` / `false` only | **call only** — `N(True = …, False = …)` |
| 4 | `VectorParameter` | declaration | `UMaterialExpressionVectorParameter` | vector literal | value, 4 components |
| 5 | `DoubleVectorParameter` | `DSH3253` | — | — | — |
| 6 | `ChannelMaskParameter` | expanded | `UMaterialExpressionChannelMaskParameter` | vector literal | `N(Input = …)`, **1** component |
| 7 | `StaticComponentMaskParameter` | expanded | `UMaterialExpressionStaticComponentMaskParameter` | none — see below | `N(Input = …)` |
| 8 | `CurveAtlasRowParameter` | `DSH3253` | — | — | — |
| 9 | `DynamicParameter` | `DSH3253` | — | — | — |
| 10 | `FontSampleParameter` | `DSH3253` | — | — | — |
| 11 | `SpriteTextureSampler` | `DSH3253` | — | — | — |
| 12 | `TextureObjectParameter` | declaration | `UMaterialExpressionTextureObjectParameter` | asset reference | value (texture) |
| 13 | `TextureCollectionParameter` | `DSH3253` | — | — | — |
| 14 | `SparseVolumeTextureObjectParameter` | `DSH3253` | — | — | — |
| 15 | `TextureSampleParameter2D` | expanded | `UMaterialExpressionTextureSampleParameter2D` | asset reference | `N(Coordinates = …)`, read as `RGBA` |
| 16 | `TextureSampleParameter2DArray` | expanded | `UMaterialExpressionTextureSampleParameter2DArray` | asset reference | as 15 |
| 17 | `TextureSampleParameterCube` | expanded | `UMaterialExpressionTextureSampleParameterCube` | asset reference | as 15 |
| 18 | `TextureSampleParameterCubeArray` | expanded | `UMaterialExpressionTextureSampleParameterCubeArray` | asset reference | as 15 |
| 19 | `TextureSampleParameterVolume` | expanded | `UMaterialExpressionTextureSampleParameterVolume` | asset reference | as 15 |

The class of an expanded token is looked up in the engine's node catalog; a class this engine does not
have is `DSH5212`.

### Type-specific metadata keys

Every token takes the generic metadata keys (`Group`, `Description`, `SortPriority`,
`Slider(min, max)`, `ParameterName`) plus any reflected UPROPERTY of its class. The class-specific keys
that matter in practice:

| Token | Keys that bind class-specific UPROPERTYs |
| :-- | :-- |
| `ScalarParameter` | `SliderMin`, `SliderMax`, `PrimitiveDataIndex` |
| `VectorParameter` | `UseCustomPrimitiveData` (binds `bUseCustomPrimitiveData`), `PrimitiveDataIndex`, `ChannelNames` |
| `ChannelMaskParameter` | `MaskChannel` (enum `EChannelMaskParameterColor`) |
| `StaticComponentMaskParameter` | `DefaultR`, `DefaultG`, `DefaultB`, `DefaultA` (booleans) |
| `TextureObjectParameter` | `Texture`, `SamplerType`, `IsDefaultMeshpaintTexture` |
| `TextureSampleParameter2D` … `TextureSampleParameterSubUV` (15–20) | `Texture`, `SamplerType`, `SamplerSource`, `MipValueMode`, `GatherMode` <Since v="5.6" ue />, `AutomaticViewMipBias`, `ConstCoordinate`, `ConstMipValue`, `IsDefaultMeshpaintTexture`; `TextureSampleParameterSubUV` adds `bBlend` |
| `RuntimeVirtualTextureSampleParameter` | `VirtualTexture`, `MaterialType`, `bSinglePhysicalSpace`, `bAdaptive`, `MipValueMode`, `TextureAddressMode` |
| `SparseVolumeTextureSampleParameter` | `SparseVolumeTexture`, `MipValueMode`, `SamplerSource`, `ConstMipValue` |

A declaration and an expanded token report a key their class lacks differently — see
[Metadata and groups](/en/docs/parameters/metadata#reflected-property-passthrough).

### Which default parser a token uses

| Tokens | Accepts | Otherwise |
| :-- | :-- | :-- |
| `ScalarParameter` | a scalar literal | `DSH3254` |
| `StaticBoolParameter`, `StaticSwitchParameter` | `true` / `false` only | `DSH3254` |
| `VectorParameter`, `ChannelMaskParameter` | a vector literal | `DSH3254` on `VectorParameter`; on `ChannelMaskParameter` an unreadable literal is dropped with no diagnostic |
| `TextureObjectParameter` | a [`Path(…)`](/en/docs/parameters/path) asset reference | resolved when the material is built: `DSH8271` / `DSH8218` |
| Texture-sample tokens 15–20 | a `Path(…)` asset reference | resolved when the material is built: `DSH8213`, quoting the resolver's code |
| `StaticComponentMaskParameter` | nothing — the class has no `DefaultValue` | the default is dropped with `DSH5288`; write `[DefaultR = true; …]` |
| `RuntimeVirtualTextureSampleParameter`, `SparseVolumeTextureSampleParameter` | nothing | the default is dropped with **no diagnostic** <Since v="2.0.0" /> |

<Callout type="warn">
**A `RuntimeVirtualTextureSampleParameter` or `SparseVolumeTextureSampleParameter` default is
ignored.** `= Path(…)` on either token reaches no property of the node, and nothing says so. Bind the
asset through metadata instead — `[VirtualTexture = Path(…)]`, `[SparseVolumeTexture = Path(…)]`.
</Callout>

A texture-sample token's default is written to the node's `Texture` property; an asset that resolves and
does not load is written as nothing, with no diagnostic, and the node then takes the engine's default
texture. **A sampler parameter with no texture still compiles**: `SetDefaultTexture()` is called for a
`UMaterialExpressionTextureSampleParameter` subclass. The runtime-virtual-texture and sparse-volume
nodes are not such subclasses and still need their asset bound.

### Dimension inference

A texture-sample token fixes a dimension by the suffix after `TextureSampleParameter`: `2D` →
`Texture2D`, `2DArray` → `Texture2DArray`, `Cube` → `TextureCube`, `CubeArray` → none (any texture),
`Volume` → `VolumeTexture`, `SubUV` → `Texture2D`; RVT and SVT are not judged. The suffix is compared
whole <Since v="2.0.0" />, so `TextureSampleParameterCubeArray` is no longer taken for a cube. The
dimension is used for one thing only: judging the class a `Class'…'` default names.

`TextureObjectParameter` declares **no** dimension: it takes the dimension of the asset its default
loads — a cube, a 2D array or a volume, else `Texture2D` — which is what lets it accept any of them
<Since v="1.6.0" />.

| Token family | What is checked |
| :-- | :-- |
| Compact `Texture2D` / `TextureCube` / `Texture2DArray` / `Texture3D` / `VolumeTexture` | the `Class'…'` shell: another dimension is `DSH1044`, a non-texture class `DSH1043`. The loaded asset is not checked <Since v="2.0.0" /> |
| `TextureObjectParameter` | the shell's "not a texture" half only (`DSH1043`) |
| Texture-sample tokens 15–17, 19, 20 | the shell, as for a compact token |
| `TextureSampleParameterCubeArray` | the shell's "not a texture" half only |
| `RuntimeVirtualTextureSampleParameter`, `SparseVolumeTextureSampleParameter` | nothing; their default is not read |

<Callout type="warn">
A `TextureSampleParameterCube` assigned a plain 2D texture by its plain object path generates without a
DreamShader diagnostic; only a `Texture2D'…'` shell gives the mismatch away (`DSH1044`). Otherwise the
mismatch surfaces later as an Unreal shader-compile error. Assign the right dimension.
</Callout>

## Using parameters in Graph

### Value reads

A property is one of two things <Since v="2.0.0" />:

- a **declaration** (every compact token, `ScalarParameter`, `StaticBoolParameter`, `VectorParameter`,
  `TextureObjectParameter`): a file-scope `uniform` or `static const`, one node however often it is
  read;
- a token **expanded at each use** (`StaticSwitchParameter`, the two masks, the texture-sample tokens):
  every read or call builds the node there, and uses written the same way share one node.

A property name is looked up ignoring case, as in 1.x; a read of a declaration that matches only in case
is `DSH5275`. A `Graph` variable of the same name hides a declaration for the rest of the body
(`DSH4251`, warning).

| Property kind | What a read is |
| :-- | :-- |
| A scalar declaration | the `ScalarParameter`'s value |
| A 2- or 3-component vector declaration | the `VectorParameter`'s `RG` / `RGB` output |
| A 4-component vector declaration, `VectorParameter` | the `RGBA` output |
| A `const` declaration | the constant node's whole value |
| A texture declaration | a texture object |
| `ChannelMaskParameter` | its one output, **1** component |
| `StaticComponentMaskParameter` | its output, as wide as its input |
| A texture-sample token (15–20) | the sample's `RGBA` output, 4 components |
| `RuntimeVirtualTextureSampleParameter`, `SparseVolumeTextureSampleParameter` | a node with several outputs |
| `StaticSwitchParameter` | not a value — see [below](#staticswitchparameter) |

So `vec2 P` reads `RG` while `VectorParameter P` reads `RGBA`.

- **Declaration order does not constrain reads.** A `Graph` may read a property declared further down.
  The exception is a `UE.*` property: it is a local declared at the head of each body that reads it, in
  `Properties` order, so an argument naming another `UE.*` property needs that one earlier in the list
  and read by the same body; otherwise the name is not declared (`DSH4200`).
- A declaration is declared at **file scope** <Since v="2.0.0" />: any block of the file can read it. A
  token expanded at its uses belongs to its own block.
- A property nothing reads builds no node (`DSH4390`, info).

A swizzle applies to the read value, not to the node: `Tint.rgb`, `Sample.a`, `UV.yx`.

### The pin call form

<Since v="1.4.1" />

```c
vec4 S = BaseTex(Coordinates = UV);
vec4 M = Keep(Input = S);
```

The call builds the property's node at this use, with the default and metadata of its declaration, and
wires each named argument to an input pin. <Since v="2.0.0" /> The node belongs to the call: two calls
with the same arguments share one node, but a bare read of the same property elsewhere is a node of its
own, without the wiring — 1.x cached one node per property and kept the first call's connections for
every later read.

There is no positional variant: every argument must be named (`DSH5259`). Each argument name is matched
against the class's input pins as the engine catalog lists them, then against its properties; a match
only ignoring case is `DSH5276`. In a 1.x source, a name the catalog does not list but whose value is a
number is taken for a pin named after the node's settings (`DSH5291`, info): the emitter connects it to
the live node's pin of that display name — or of the display name with every character an identifier
cannot hold turned into `_` — or refuses it (`DSH8212`). Any other unknown name is `DSH5213`. Argument
values are ordinary expressions, converted to the pin's type; one that does not convert is `DSH5214`. An
output selector (`Output = …`, `OutputIndex = …`) on the call is `DSH5265`.

The call form is for the tokens expanded at their uses:

```text
ChannelMaskParameter                  TextureSampleParameterCubeArray
StaticComponentMaskParameter          TextureSampleParameterVolume
TextureSampleParameter2D              TextureSampleParameterSubUV
TextureSampleParameter2DArray         RuntimeVirtualTextureSampleParameter
TextureSampleParameterCube            SparseVolumeTextureSampleParameter
```

A call on a declaration — every compact token, `ScalarParameter`, `StaticBoolParameter`,
`VectorParameter`, `TextureObjectParameter` — is `DSH4208`: it names no function.

<Callout type="warn">
**A compact `Texture2D` cannot be called.** A texture object has no input pins. Read it as a value and
feed it to a sampler, or declare a `TextureSampleParameter2D` in the first place.
</Callout>

### Pin names by parameter type

The catalog lists a pin under the engine's C++ name for it, with the display name in identifier form as
an alias where the two differ. <Since v="2.0.0" /> Every pin is reachable that way — 1.x matched display
names only, and those with a space or parentheses could not be written.

| Parameter type | Pins the catalog lists | Display names a 1.x call can still use (`DSH5291`) |
| :-- | :-- | :-- |
| `ChannelMaskParameter` | `Input` | — |
| `StaticComponentMaskParameter` | `Input` | — |
| `TextureSampleParameter2D` … `TextureSampleParameterSubUV` | `Coordinates`, `TextureObject`, `MipValue`, `CoordinatesDX`, `CoordinatesDY`, `AutomaticViewMipBiasValue` (alias `Apply_View_MipBias`) | `MipLevel` under `[MipValueMode="MipLevel"]`, `MipBias` under `[MipValueMode="MipBias"]`, `DDX_UVs_` / `DDY_UVs_` under `[MipValueMode="Derivative"]` |
| `RuntimeVirtualTextureSampleParameter` | `Coordinates`, `WorldPosition` (alias `World_Position`), `MipValue`, `DDX`, `DDY` | the names the node shows for its settings |
| `SparseVolumeTextureSampleParameter` | `Coordinates`, `TextureObject`, `MipValue`, `CoordinatesDX`, `CoordinatesDY` | — |
| `StaticSwitchParameter` | **separate form**: `A` (alias `True`), `B` (alias `False`) | — |

<Callout type="warn">
**Leave `TextureObject` unwired on a texture-sample *parameter* node.** Unreal's
`UMaterialExpressionTextureSampleParameter` constructor clears `bShowTextureInputPin`, and a loaded asset
drops any connection to the hidden pin. Set the asset with the default or with `[Texture=Path(…)]`.
`SparseVolumeTextureSampleParameter` is the exception — it does expose that pin.
</Callout>

### StaticSwitchParameter

A static switch has its own call form and **cannot be read as a value**:

```c
vec3 C = UseDetail(True = DetailColor, False = BaseColor);
vec3 D = UseDetail(A = DetailColor, B = BaseColor);
vec3 E = UseDetail(DetailColor, BaseColor);          // positional, in that order
```

The true branch is `True=`, else `A=`, else the first positional argument; the false branch `False=`,
else `B=`, else the second. Both are required (`DSH5258`); any other argument is dropped with `DSH5254`,
and an output selector is `DSH5265`. The branches are wired to the node's `A` and `B` pins, which take
any width; the result is as wide as the wider branch, or the material or Substrate value a branch
carries. <Since v="2.0.0" /> The 1.x checks on the branches — no texture object, no `Substrate` or
`MaterialAttributes` mixed with a number, equal component counts — are not made as such: a branch the
pin cannot take is `DSH5214`.

The node's `DefaultValue` is the declaration's default (`true` or `false`; the node's own `false` when
there is none), and the switch is registered as a static parameter of the material. A bare `UseDetail` —
or `UseDetail.r` — is no declared name: `DSH4200`.

To build the same node in place without declaring it in `Properties` first, use the anonymous
[`UE.StaticSwitchParameter`](/en/docs/builtins/ue-nodes#uestaticswitchparameter).

## Tokens not valid in `Properties`

These are real DreamShaderLang type tokens in other contexts. In a `Properties` declaration each of them
is `DSH3252` — except `StaticBool`.

| Token | Valid where instead |
| :-- | :-- |
| `MaterialAttributes` | `Inputs` / `Outputs` / `Results` of a material function; `Shader` `Outputs` declarations; `Function` signatures |
| `Substrate` | same as above, and only on <Since v="5.4" ue /> |
| `SamplerState` | `Inputs` / `Outputs` / function signatures, where it is an alias for `Texture2D` |
| `StaticBool` | `Inputs` / `Outputs` of a material function. In `Properties` it is accepted <Since v="2.0.0" /> but read as `bool` — it makes a **dynamic** `ScalarParameter`, not a static bool: write `StaticBoolParameter` for that |
| `mat2` / `mat3` / `mat4` | a `Function` signature or `Code` body only, where the parser normalizes them to `float2x2` / `float3x3` / `float4x4`; generation then rejects the matrix type |

The full cross-context matrix is in [Types and values](/en/docs/language/types-and-values).

## Naming rules

- **A property name is an identifier** <Since v="2.0.0" />. `float 1Bad = 0;` is `DSH2105` (a malformed
  number) and `DSH3250`.
- **A property that becomes a declaration is declared at file scope** <Since v="2.0.0" />. Two properties
  of one name — in one block, or in two blocks of the same file — are `DSH4210`. Names are compared
  exactly. The 1.x rule that a function's property may not share a name with one of its inputs has no
  2.0 check.
- `[ParameterName="…"]` changes only the name the material exposes to instances and Blueprints; `Graph`
  still uses the declared identifier.
- Inside a `VirtualFunction`, `Properties` is a synonym for `Inputs` and takes the typed-parameter
  grammar, not this one.

## Example

```c
Shader(Name="Docs/M_ParameterNodes")
{
    Properties = {
        const float Gamma = 2.2;                       // Constant

        Group("Surface") {
            TextureSampleParameter2D BaseTex = Path(Game, "Textures/T_White") [
                SamplerType   = "LinearColor";
                SamplerSource = "FromTextureAsset";
                MipValueMode  = "None";
            ];
            ScalarParameter Roughness = 0.55 [Slider(0, 1)];
            VectorParameter Tint      = float4(1.0, 0.8, 0.6, 1.0);
        }

        Group("Masks") {
            ChannelMaskParameter         Pick = float4(1, 0, 0, 0) [MaskChannel = "Red"];
            StaticComponentMaskParameter Keep [DefaultR = true; DefaultG = true];
        }

        StaticSwitchParameter UseDetail = true [Group="Switches"];

        UE.TexCoord(Index = 0) UV;
    }

    Settings = { Domain = "Surface"; ShadingModel = "DefaultLit"; BlendMode = "Opaque"; }

    Outputs = {
        vec3  Color;
        float Rough;

        Base.BaseColor = Color;
        Base.Roughness = Rough;
    }

    Graph = {
        vec4  Sample = BaseTex(Coordinates = UV);
        vec4  Masked = Keep(Input = Sample);
        float Chan   = Pick(Input = Sample);

        Color = UseDetail(True = Masked.rgb, False = Tint.rgb) * Gamma;
        Rough = Roughness * Chan;
    }
}
```

Generated nodes:

```text
Constant(2.2)                 Gamma
TextureSampleParameter2D      BaseTex    SamplerType=LinearColor
ScalarParameter               Roughness  Group="Surface" SortPriority=0  SliderMin=0 SliderMax=1
VectorParameter               Tint       Group="Surface" SortPriority=10
ChannelMaskParameter          Pick       MaskChannel=Red
StaticComponentMaskParameter  Keep       DefaultR/G=true
StaticSwitchParameter         UseDetail  Group="Switches"
TextureCoordinate             UV         CoordinateIndex=0
```

`BaseTex`, `Pick` and `Keep` are expanded tokens, so their `Group(…)` scopes do not stamp them
<Since v="2.0.0" />, and `Roughness` takes counter slot 0.
