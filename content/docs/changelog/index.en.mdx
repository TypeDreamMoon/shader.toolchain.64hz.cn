<Callout type="info">
The plugin page is generated from the plugin's own `CHANGELOG.md`, which ships inside the plugin
folder — that file is the record of authority when this page and your installed copy disagree.
</Callout>

Worth checking all three at release time:

- The plugin version lands in `DreamShader.uplugin`.
- The extension version lands in `package.json` and in the install script.
- The site updates its current-version tables, the affected feature pages, and the record here.
