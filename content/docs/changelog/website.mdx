这里记录 `shader.toolchain.64hz.cn` 文档站本身的信息架构、部署和内容更新。

## 2026-08-21

### 同步到插件 1.8.0

一次覆盖 `1.5.1` → `1.8.0` 四个版本的内容同步。除更新记录外，改动集中在生成器语义变化最大的那几页。

- [插件更新记录](/docs/changelog/dreamshader)补齐 `1.5.1`、`1.6.0`、`1.7.0`、`1.7.1`、`1.8.0`；
  全站当前版本表改为 `1.8.0`。
- [重新生成](/docs/generation/regeneration)重写：新增**手改检测**（输出指纹、四种状态、什么算手改、
  三个出口）、**原子重建**、**资产开着编辑器时拒绝重建**；「source hash 缓存」改写成**构建键**，
  并补上按依赖顺序编译的批次规则。归属守卫那条「ThinCustom 路径上没有守卫」的警告已作废并删除。
- [内存材质](/docs/generation/in-memory)的「被已保存资产遮蔽」换成**存储决定一次重建怎么落地**，
  并说明启动扫描不再强制重建；cook 一节补上 AssetRegistry 注册。
- [数学内置](/docs/builtins/math)从 19 个写法扩到 29 个，含 `reflect` / `refract` 的子图展开、
  `step` 的 pin 反向映射，以及「这里没有的东西」重写。全站凡是写「19 个」的地方一并更正。
- [import](/docs/language/imports) 与[工程结构](/docs/start/project-layout)补上**插件源码根**、
  「import 永不跨根」和带根限定的 `Plugin.<Name>:path` 写法。
- [编辑器工具](/docs/tools/editor)补上右键菜单的三个 provenance 动作、Graph 断点、原始 RGBA8 帧与空闲退避、
  `status.json` / `Responses/` / `owner.lock`，以及**一个工程只有一个编辑器持有 bridge**。
- [VSCode 与 Rider](/docs/tools/vscode)更正了两处已经不成立的说法：请求不再是「静默消失」（带 `requestId`
  会有回复文件），`previewControl` 省略 `frameRate` 也不再把会话掉到 2 FPS。
- [错误速查](/docs/diagnostics)新增 `DSHnnnn` 错误码分段表，并写明只有 parser 侧已标注。
- [运算符与转换](/docs/graph/expressions)新增「swizzle 在图里长什么样」—— 内联 mask、改指输出、
  `ComponentMask` 节点三选一，以及材质编辑器为什么会把内联 mask 改判到最后一个输出。
- [项目设置](/docs/settings/project)从 13 项到 15 项（`bScanPluginSourceDirectories`、
  `bLayoutInMemoryGraphs`）；[材质 Settings](/docs/settings/material) 补上由 domain 推导的
  `bUsedWithVolumetricCloud`；[函数](/docs/language/functions)补上顶部 `#include` 的提升；
  [Properties 类型](/docs/parameters/properties)与 [`UE.*` 节点](/docs/builtins/ue-nodes)补上
  纹理维度按 `GetMaterialType()` 判断、以及 `UE.CollectionParam` 的宽度。

## 2026-08-19

### 域名迁移到 shader.toolchain.64hz.cn

文档站从 `lang.64hz.cn` 迁到 `shader.toolchain.64hz.cn`，与 DreamFX 的
[`fx.toolchain.64hz.cn`](https://fx.toolchain.64hz.cn/) 一起收进 `*.toolchain.64hz.cn`
命名下，GitHub 仓库同步改名。

- 插件描述符的 `DocsURL`、两份 README、`Docs/` 与发布流程里指向文档站的链接全部改指新域名。
- 站内链接不受影响 —— 全部是站内相对路径。
- **旧域名没有做 301。**`lang.64hz.cn` 目前直接不解析，迁移之前发出去的链接（包括已安装插件里
  写死的 `DocsURL`）会连接失败而不是跳转过来。

## 2026-08-02


### 文档重建 —— 插件 1.5.0

- 整套文档重构成 **13 个栏目**：概览、快速开始、语言核心、Graph 语言、内置节点、参数、设置、生成与产物、
  工具链、诊断、示例、HLSL / GLSL 背景、ChangeLog。
- 所有页面按插件自带的参考手册重写。该手册由插件源码推导并对照源码校验过，现在是本站的事实来源；
  页面写的是实际行为、诊断文本和穷尽表格，而不是对旧文档的转述。
- `getting-started/`、`dreamshader/`、`syntax/`、`reference/`、`compiler/` 和 `workflows/`
  栏目由新的目录树取代，内容全部并入新栏目。
- 补齐 `1.5.0` 的能力面：统一的 [ThinCustom backend](/docs/settings/backend)、
  [内存材质](/docs/generation/in-memory)、[Material Content Browser](/docs/tools/editor)，
  以及可省略的 section `=`、`Group()` 作用域和 `Slider()`。
- 修正旧页面长期存在的错误：`Substrate.*` 需要 **UE 5.4+**，不是 5.7；项目设置在
  **DreamPlugin ▸ Dream Shader** 下，一共 **13** 项；`if (Mask)` 按 `!= 0` 接线，负值同样走 then 分支；
  只有通用 `UE.Expression` / `Substrate.*` 调用和数学内置会复用节点；类名带 `U` 前缀永远解析不到；
  `MaterialLayer` / `MaterialLayerBlend` 自 1.3.0 起已弃用。
- 当前版本表同步到插件 `1.5.0`，引擎 Unreal Engine `5.3` 到 `5.8`。

### 自动部署

- 新增 GitHub Actions 部署工作流，推送到 `main` / `master` 或手动触发时会执行 typecheck、build 和 SFTP 上传。
- 部署脚本统一到 `upload.js`，通过 `SFTP_HOST`、`SFTP_USER`、`SFTP_PASSWORD` / `SFTP_PRIVATE_KEY`、
